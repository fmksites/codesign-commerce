# Working rules

## Current phase

The concept and architecture were approved and the public implementation is in
release preparation. Local maintenance, tests, and documentation improvements
may proceed when requested. Pushing, deploying, publishing, changing a Shopify
theme, enabling the private KORRHAUS feature, or promoting production traffic
requires a separate explicit owner approval.

## Project boundaries

- This repository is the public CoDesign WebMCP challenge project.
- The KORRHAUS production application remains private and is not part of this
  repository.
- Do not copy secrets, credentials, customer records, prices, margins, supplier
  data, private endpoints, or administrative logic into this project.
- Merchant integrations consume the public package through a narrow adapter.

## Product standard

- Solve configurable-commerce problems rather than demonstrating WebMCP for
  its own sake.
- Preserve a complete normal human interface when WebMCP is unavailable.
- Agent proposals must be visible and temporary until the page's human Keep or
  Revert action.
- Do not add WebMCP tools for save, upload, quote acceptance, order, checkout,
  payment, customer data, pricing, suppliers, or private workflows.
- Verify the actual deployed experience as well as source and automated tests.

## Challenge evidence

- Clearly distinguish the pre-existing KORRHAUS Sock Designer from work added
  after 25 August 2026.
- Keep current instructions separate from dated historical evidence.
- The public repository must retain real source, assets, license, runnable
  instructions, tests, and a reproducible demonstration.
- Do not describe local, historical, zero-traffic, or Codex-only evidence as a
  broader live-client claim.
