The Shopify handoff point

After product discovery.
Before anything is cart-ready.

Shopify handles catalog, navigation, cart, checkout, and orders. CoDesign WebMCP handles the interdependent configuration work inside the merchant's live page.

  1. 01ReadAllowlisted live state and revision
  2. 02ProposeAtomic, visible, zero-write preview
  3. 03PreviewGenuine render per product variant
  4. 04DiagnoseTargeted production issue and bounded repair
  5. 05RevalidateFresh preview proves the repair
  6. 06Human decidesKeep issues a verified configuration receipt; Revert writes nothing

The deliberate boundary

The agent never gets the last click.

A proposal may coordinate choices and update the real preview. Only the person can cross the existing persistence boundary.

Visible to the agentPublic configuration, options, dependencies, validation

Visible to the personEvery preview change, missing decision, Keep and Revert

Never exposed as toolsSave, upload, quote, order, checkout, payment, customer or private commercial data

After the person chooses Keep

A verified configuration Shopify can safely reference.

The Configuration Passport binds the committed revision, public-safe digest, renderer versions and exact preview receipts. It excludes artwork, shopper data, prices, prompts and private production rules.
