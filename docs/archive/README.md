# Historical project archive

Files under `docs/archive/` and `docs/hackathon-build/` document how the project
was scoped and implemented during the challenge. They are retained for
timestamped provenance, not as current setup or release instructions.

Historical documents may contain:

- the former **CoDesign Commerce** name;
- earlier one-tool and five-tool prototypes;
- superseded repository or deployment URLs;
- old test counts, hashes, and browser states; or
- planning gates that have since been completed.

Use the repository [README](../../README.md), [START_HERE](../../START_HERE.md),
[current browser matrix](../BROWSER_SUPPORT.md), and
[evidence index](../evidence/README.md) for current claims.

## Project-history files

`project-history/` contains the original execution plan, initial project brief,
private-repository planning snapshot, prior public/private boundary, early
visual QA notes, and the prompt used to begin the implementation task.
