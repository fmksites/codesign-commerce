# Devpost submission copy

The canonical editable Devpost draft is
[`devpost-submission.md`](../devpost-submission.md). It contains the product
description, judge instructions, implementation explanation, required form
answers, known limitations, and the remaining human-owned video and attestation
fields.

Maintain only that file during submission preparation. This pointer exists so
older documentation links do not create a second competing version of the
submission copy.

The canonical judge journey that submission copy must describe is:

1. the ordinary North Form brief in [`START_HERE.md`](../START_HERE.md);
2. truthful page-tool disclosure and actual invocation activity;
3. two temporary renderer previews with `persisted: false`;
4. a visible charcoal safe-zone diagnosis;
5. only the merchant-declared 78% repair, followed by rerender and revalidation;
6. human Revert for the repeatable scored flow; and
7. a separate exactly-once human Keep proof that issues a Configuration
   Passport and opaque Shopify-safe reference.

Do not add final-client, deployment, video, or test-count claims to the Devpost
draft until the exact release evidence supports them. At the time of this edit,
the improved exact-current ChatGPT desktop/native-Chrome acceptance remains
pending.
