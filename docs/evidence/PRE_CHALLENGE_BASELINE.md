# Pre-challenge KORRHAUS baseline

Captured on 26 August 2026 to distinguish the existing merchant product from
work created during the challenge implementation window.

## Existing product

KORRHAUS already operated its production Custom Sock Designer before the
challenge. Existing capabilities included a visual sock preview, multiple
designs and quantities, yarn colours and patterns, logo and cuff choices,
grip-sole choices, packaging, validation, and project persistence.

The challenge submission does not claim those product capabilities as new.
The post-start work is the public CoDesign WebMCP transaction engine, manifest
and adapter contracts, webpage tool registration, temporary proposal review,
autosave isolation, portability example, tests, and reproducible evidence.

## WebMCP attribution boundary

Read-only inspection before implementation found no Custom Sock Designer
registration using `document.modelContext.registerTool(...)`. KORRHAUS also
had a separate read-only remote MCP planning service; that service is not the
page-scoped WebMCP implementation submitted here.

The post-start public Git history begins with commit
`abf2a7829fdd188c2f2492e9c9d53a247a6ede7f`, committed on 26 August 2026 after
implementation authorization. Subsequent public commits provide the review
controller, exact-six tool contract, tote portability example, tests, and
release evidence.

## Evidence qualification

The pre-existing product and post-start public implementation are separate
claims. Historical reachability or private build records do not by themselves

[public-safe KORRHAUS live verification](./KORRHAUS_LIVE_WEBMCP_2026-08-31.md)
